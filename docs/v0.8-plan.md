# v0.8 — Encrypted Experience Memory: task list

Direction brief: `Regurgitate_v0.8_Encrypted_Experience_Action_Plan.docx`
(summarised in [ADR 0001](adr/0001-bounded-semantic-experience.md)).

Invariant for the whole release: **retain bounded semantic experience, never
raw work history.** Every phase below must leave the privacy tests green.

Legend: `[x]` done · `[ ]` open · `[~]` partial / opportunistic

## Phase 0 — Baseline and privacy contract

- [x] ADR recording the new invariant and what stays unchanged
- [x] Admission fuzz fixtures: prompts, code, commands, URLs, paths, secrets,
      provider payloads must be rejected by capsule admission
- [x] Encryption-boundary test: capsule `situation`/`lesson`/`caveat`/tags never
      appear in SQLite bytes
- [x] Paired cold/warm benchmark protocol (`benchmarks/README.md`) and a
      `bench-report` command computing token savings, token ROI, retry
      reduction from a JSONL of paired runs
- [ ] Baseline numbers from current master committed to `benchmarks/` (needs
      real agent runs; protocol and tooling are in place)

## Phase 1 — Schema v3: `ExperienceCapsule`

- [x] `BoundedText<N>` with serialization-time length caps and structural
      admission checks (no URLs, paths, command shapes, secrets, code blocks)
- [x] Controlled vocabularies: `MemoryScope`, `ApplicabilityTags`
      (`ArtifactKind`, `Phase`, `Ecosystem`, `ToolFamily`, `RiskShape`),
      `EnvironmentFingerprint`, `FailureReason`, `MemoryLifecycle`,
      `SemanticOutcome`
- [x] `ExperienceCapsule` (schema v3) with embedded bounded evidence log
- [x] Separate `experiences` table; private payload encrypted with an
      authenticated envelope; structural plaintext limited to id, scope token,
      timestamps, versions
- [x] `HookExecution` rows untouched; old `LearnedPractice` rows still decode

## Phase 2 — Compositional `Procedure`

- [x] `Procedure { mutation, verification, execution, research, integration,
      steps }` and `ProcedureStep`
- [x] `Strategy -> Procedure` migration mapping with round-trip tests
- [x] `Strategy` retained as a compatibility input only (`learn` shorthand)

## Phase 3 — Hierarchical scope

- [x] Scope tokens for project / workspace / ecosystem / machine / global
- [x] Retrieval expands outward only when local evidence is sparse
- [x] Isolation test: another project's project-scoped capsule never surfaces
- [x] Scope prior test: equal applicability, project beats global

## Phase 4 — Evidence mathematics

- [x] One `RankingPolicy` object owning every weight, half-life, and threshold
- [x] Recency decay `exp(-ln2 · Δt / H)` with per-scope half-lives
- [x] Applicability score `0.35T + 0.25A + 0.20E + 0.10P + 0.10V`
- [x] Per-evidence weight `W_scope · w_age · a · W_lifecycle`
- [x] Beta posterior (uniform prior), 80 % credible interval, Kish `n_eff`
- [x] Guidance gate: `prefer` iff `L ≥ 0.65`, `avoid` iff `U ≤ 0.35`,
      neither without `n_eff ≥ 2.5`
- [x] Test: 2/2 successes cannot produce strong guidance; stale evidence decays

## Phase 5 — Two-stage retrieval

- [x] `EphemeralTaskContext`: explicit controlled metadata outranks keyword
      inference; query text is transient
- [x] Stage 1: coarse scope/metadata candidate window (no decrypt)
- [x] Stage 2: bounded decrypt, applicability + evidence, cluster by controlled
      identity, rank, serialise, trim to token budget
- [x] Legacy v2 practice rows materialise as one-step legacy capsules and rank
      below equally relevant v3 capsules
- [x] `recall` gains `--task --phase --artifact --ecosystem --tool-family`
- [~] Zeroize transient buffers: query text and the classifier's lowercase
      copy are zeroized; decrypted capsule vectors are dropped at the end of
      the call but not explicitly zeroized

## Phase 6 — RecallBroker

- [x] Host-neutral `RecallBroker` port producing a plain-text experience brief
- [x] `regurgitate preflight` (Tier C): emits the brief for a startup channel
- [x] Preflight stays silent for prompts that map to no controlled task and
      never injects limited-evidence hints
- [x] `regurgitate preflight --agent claude` (Tier A): reads a Claude Code
      `UserPromptSubmit` payload, classifies ephemerally, returns
      `additionalContext`; silent and empty when nothing is relevant
- [x] Claude config printer/installer gains the `UserPromptSubmit` hook
- [x] Skill revised: recall once for non-trivial tasks, pass controlled
      metadata, record or confirm one capsule per milestone
- [~] Codex / AoE automatic preflight — deferred until those hosts expose a
      stable pre-task lifecycle hook

## Phase 7 — Compaction (shipped early because it gates capsule growth)

- [x] `experience record` confirms an equivalent active capsule instead of
      inserting a paraphrase duplicate
- [x] Contradicting lesson in the same applicability region marks both
      `challenged`
- [x] `experience supersede` / `experience challenge` / `experience obsolete`
- [x] `forget` and `prune` operate on capsules transactionally

## Phase 8 — Evaluation gate

- [ ] Run the paired suite; require no privacy regression, no correctness
      regression, positive median token savings on memory-relevant tasks,
      lower failed-action count, near-zero overhead on irrelevant tasks
- [ ] Only then: additional adapters and further automatic injection
